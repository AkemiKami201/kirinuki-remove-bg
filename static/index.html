Advanced options (edge refinement)

ViTMatte turns the hard mask into a real alpha channel with a network. Better on fine detail than the classic alpha matting below, and it cannot fail to converge. Both do the same job, so only one can be on at a time. It roughly triples peak memory, so on a machine with little RAM free it can be refused - the server checks before starting.

Lower the erode value (2-5) for parts with thin structures or narrow gaps: the default of 10 eats fine detail before refining.

Crops each exported image to the subject's bounding box, which is what most product catalogues expect. Padding keeps a margin of that many pixels around it. Applies to downloads only - the result on screen is untouched.

Normally the background is painted in the browser, which rebuilds the image and loses its metadata. Applying it here bakes it in during processing instead, so a white catalogue background keeps the camera data. The result arrives already flattened, so it is no longer transparent.
